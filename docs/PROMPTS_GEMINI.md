# Valtheria — pedidos de imagem para o Gemini

Arquivo gerado por `cliente-godot/ferramentas/catalogo_arte.py`. Não edite à mão: mude o script e rode de novo.

## Como usar

1. Use o Gemini pago com o modelo de imagem de maior qualidade (Nano Banana Pro). Uma conversa nova para cada personagem, arma ou monstro.
2. Copie o texto do bloco **Prompt** inteiro, sem cortar. Ele já traz as regras de fundo, luz, pose e medidas.
3. Formato: use a proporção indicada em cada item (ex.: 3:4). Resolução: a maior disponível (2K ou 4K).
4. **Personagens:** depois da imagem de frente, na mesma conversa, peça as vistas de lado e de costas com os textos da seção *Vistas extras*. O Meshy aceita até 4 imagens do mesmo personagem e o modelo 3D sai muito melhor.
5. Salve cada imagem com o nome indicado em **Arquivo** (ex.: `raca_humano_m_pesada.png`). As vistas extras levam `_lado` e `_costas` no fim.
6. Confira a imagem antes de salvar (lista na seção *Conferência*). Se falhar em algum ponto, peça no mesmo chat: *"Refaça corrigindo: …"*.
7. Junte tudo numa pasta `Valtheria-imagens`, compacte em .zip e envie ao Robson. Ele me passa e eu faço o 3D, o encaixe e coloco no jogo.

**Por que tudo isso:** o Meshy transforma a imagem em 3D. Fundo liso, luz igual, pose A e mãos vazias fazem o modelo sair limpo, com braços e pernas separados para o esqueleto. As armas saem separadas do corpo para poder trocar de equipamento e de grau, e com cabo reto e medido para a mão fechar em volta dele.

**Ordem sugerida:** raças (seção 1) → armas grau NG (seção 2, só os `_ng` primeiro) → pranchas de pegada (3) → monstros (4) → árvores (5) → muralha (6) → luzes (7) → céus (8) → texturas (9) → demais graus de arma.

## Opção: gerar tudo de uma vez pela API (para quem tem chave do Gemini)

Em vez de copiar e colar, o script `cliente-godot/ferramentas/gerar_imagens_gemini.py` faz os mesmos pedidos em lote e salva com os nomes certos:

```
pip install google-genai pillow
set GEMINI_API_KEY=sua-chave        (Windows; no Linux/Mac: export GEMINI_API_KEY=sua-chave)
python gerar_imagens_gemini.py --listar
python gerar_imagens_gemini.py --grupo 1 --vistas      (raças, com lado e costas)
python gerar_imagens_gemini.py --grupo 2 --so-ng       (armas grau NG)
python gerar_imagens_gemini.py --grupo 4 --vistas      (monstros)
```

O que já foi gerado é pulado, então dá para parar e continuar. Esse script não foi testado com uma chave real; se a API recusar o nome do modelo, use `--modelo` com o nome que o Google AI Studio mostrar.

## Depois das imagens (parte do Claude)

1. Cada imagem vira modelo 3D no Meshy (Imagem para 3D, Meshy 6 Lite, com textura, licença CC BY 4.0).
2. Raças: o script `pele_automatica.mjs` liga o modelo ao esqueleto do jogo (as animações passam a funcionar).
3. Armas: o script `encaixe_armas.mjs` põe o ponto da mão, a direção da lâmina e o tamanho em metros, conforme a tabela de medidas acima. O jogo carrega de `assets/armas/<id>.glb` e fecha os dedos no cabo.
4. Monstros, árvores, muralha, luzes, céus e texturas entram no jogo na rodada de correções.


## Conferência antes de salvar

- Fundo cinza liso, sem chão, sem sombra, sem texto, sem marca d'água visível.
- Personagem: corpo inteiro, pose A, mãos vazias e com dedos visíveis, nada cobrindo braços e o espaço entre as pernas, sem capa.
- Arma: inteira, de pé, reta, cabo cilíndrico separado da guarda e do pomo. Uma arma só por imagem.
- Árvore: folhas desenhadas uma a uma nas bordas, nada de bola lisa; tronco e base visíveis.
- Muralha: as pontas das peças retas e lisas (precisam encaixar umas nas outras).
- Céu: formato 2:1, sem chão, as bordas esquerda e direita combinam.

## Vistas extras (só personagens e monstros humanoides)

Na mesma conversa, depois da imagem de frente:

```
Now show this exact same character (same face, body, outfit, colours and proportions) from the left side (profile, facing left) view, same A-pose, same plain mid-grey background, same lighting, full body, no text.
```
```
Now show this exact same character (same face, body, outfit, colours and proportions) from the back view, same A-pose, same plain mid-grey background, same lighting, full body, no text.
```

## O que estes pedidos corrigem no jogo

| Problema visto | O que resolve | Quem faz |
|---|---|---|
| Árvores sem folhas, com cara de polígono | Seção 5 (árvores com folhas desenhadas) + folhas com transparência e distância de desenho no jogo | Imagens: criador · Código: Claude |
| Personagem e monstros sem pisar no chão | Modelos novos com pés planos e medidas certas + ajuste dos pés no terreno no jogo | Imagens: criador · Código: Claude |
| Muros desencaixados | Seção 6 (kit modular com medidas fixas) + encaixe por grade seguindo o terreno | Imagens: criador · Código: Claude |
| Noite sem luz nas estradas e cidades | Seção 7 (postes, tochas, lanternas) + luzes acesas à noite no jogo | Imagens: criador · Código: Claude |
| Sem lua, estrelas e sensação de distância | Seção 8 (céus) + névoa de distância e luz da lua no jogo | Imagens: criador · Código: Claude |
| Arma não segura firme na mão | Seções 2 e 3 (cabo reto e medido, pranchas de pegada) + dedos fechando no cabo e encaixe automático | Imagens: criador · Código: Claude (já começou) |
| Chão repetido e sem profundidade | Seção 9 (texturas que se repetem sem emenda) | Imagens: criador · Código: Claude |
